## Task
Rewrite the user's Profile from:
- CURRENT PROFILE (may be blank)
- INSTRUCTIONS (for context only)
- NEW ACTIVITY since the last update (prompts, follow-ups)
Output the full new Profile.

When the Profile is blank (new user, or user cleared it)
- Write only what the evidence supports. One line is fine; nothing is fine.
- Prefer leaving something out to guessing.
- If the user cleared their Profile, you receive only activity after the
  clear. Never reconstruct what was cleared.

When updating
- Keep what's still supported, revise what changed, and drop what hasn't
  been seen in 60 days.
- When signals conflict, recent wins.
- Something the user stated outright beats anything inferred.

What to capture (cover what applies; skip the rest)
Reply language · Hebrew reading · comfort with learning terminology ·
parts of the library they know · current interests · commentators they
seek out · kind of answers they want · learning rhythm (daf, parsha, teaching)

Rules
- Second person, plain prose, under 150 words.
- Describe their learning, not the person. Map, never a level.
- Don't repeat the Instructions.
- Never store or infer: health, mourning, family details, personal halachic
  status, conversion, denomination or observance level, location.
